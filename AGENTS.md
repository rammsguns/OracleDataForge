# App startup

Always start the app bound to `0.0.0.0` so it is reachable from other devices. Start Vite with `npm run dev -- --host 0.0.0.0` and use `HOST=0.0.0.0` for the backend. Preserve the backend's required authentication and encryption configuration when using this host.

# Pull requests and merges

Always use the `oracle-dataforge-pr-merge` skill when creating, publishing, verifying, or merging pull requests for this project. Locate its `SKILL.md` through the available skills catalog and follow its workflow, including any applicable fallback reference.
